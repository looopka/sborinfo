# SborInfo Bot — Инструкция по использованию

Телеграм-бот для сбора файлов от участников событий с автоматической загрузкой на Яндекс Диск.

---

## Для пользователя

### Как начать

1. Получите **пригласительную ссылку** от администратора
2. Нажмите на ссылку — бот автоматически подключит вас к событию
3. Вы увидите сообщение: «Вы подключены к событию ...»

### Меню

| Кнопка | Что делает |
|--------|-----------|
| 📤 Загрузить файл | Отправить файлы в событие |
| 📋 Мои события | Посмотреть список ваших событий |

### Как загрузить файлы

1. Нажмите **📤 Загрузить файл**
2. Если у вас несколько событий — выберите нужное
3. Отправьте файлы (фото, видео, документы, аудио) — можно несколько за раз
4. Когда закончите, напишите **комментарий** или нажмите **⏭ Пропустить комментарий**
5. Бот загрузит все файлы на Яндекс Диск и покажет результат

> Можно также просто отправить файл боту без нажатия кнопки — бот предложит выбрать событие.

## Для администратора

### Меню

| Кнопка | Что делает |
|--------|-----------|
| ➕ Создать событие | Создать новое событие для сбора файлов |
| 📅 Мои события | Список ваших событий и управление ими |
| 🔗 Пригласительные ссылки | Управление ссылками-приглашениями |
| 📤 Загрузить файл | Загрузить файлы (как обычный пользователь) |

### Как создать событие

1. Нажмите **➕ Создать событие**
2. Введите **название** события (минимум 2 символа)
3. Введите **описание** (или отправьте `—` чтобы пропустить)
4. Событие создано! Бот предложит сразу создать пригласительную ссылку

### Как пригласить участников

1. Нажмите **🔗 Пригласительные ссылки**
2. Выберите событие
3. Нажмите **🔗 Создать ссылку**
4. Бот сгенерирует ссылку вида `https://t.me/имя_бота?start=токен`
5. Отправьте эту ссылку участникам

### Управление событиями

В разделе **📅 Мои события** нажмите на событие, чтобы увидеть действия:

| Кнопка | Что делает |
|--------|-----------|
| ✅ / ❌ Активировать/Деактивировать | Включить или приостановить приём файлов |
| 🔗 Создать ссылку | Создать новую пригласительную ссылку |
| 📊 Загрузки | Посмотреть все загруженные файлы |
| 🗑 Удалить событие | Удалить событие из бота (файлы на Яндекс Диске сохранятся) |

### Управление ссылками

В разделе **🔗 Пригласительные ссылки** нажмите на ссылку, чтобы:

| Кнопка | Что делает |
|--------|-----------|
| ✅ / ❌ Активировать/Деактивировать | Включить или отключить ссылку |
| 🗑 Удалить ссылку | Удалить ссылку из бота |

### Уведомления

При каждой загрузке файлов вы автоматически получите уведомление с информацией:
- Кто загрузил
- В какое событие
- Список файлов
- Комментарий пользователя
- Время загрузки

## Для суперадминистратора

Суперадминистратор имеет **все возможности администратора**, плюс:

### Дополнительное меню

| Кнопка | Что делает |
|--------|-----------|
| 👥 Управление администраторами | Добавить, удалить, просмотреть администраторов |

### Управление администраторами

Нажмите **👥 Управление администраторами**, затем:

| Кнопка | Что делает |
|--------|-----------|
| ➕ Добавить администратора | Назначить пользователя администратором (по Telegram ID или @username) |
| ➖ Убрать администратора | Снять роль администратора |
| 📋 Список администраторов | Посмотреть всех текущих администраторов |

> Чтобы добавить администратора, пользователь должен сначала написать боту (нажать /start).

## Структура файлов на Яндекс Диске

Загруженные файлы сохраняются по пути:

```
SborInfo/
  └── Название события/
        ├── username/
        │     └── 2026-02-28/
        │           ├── 001_photo_abc.jpg
        │           ├── 002_video_def.mp4
        │           └── 003_document.pdf
        └── report.xlsx    ← автоматический Excel-отчёт
```

Excel-отчёт обновляется автоматически при каждой загрузке.
